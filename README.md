## Quick start

```bash
git clone https://github.com/devlinmarsh/seedance-2-5-api-quickstart
cd seedance-2-5-api-quickstart
export SEEDANCE_API_KEY=your-key            # create one at argolink.io
python seedance25.py "A slow aerial shot over a foggy pine forest at sunrise"
# or
node seedance25.mjs "A slow aerial shot over a foggy pine forest at sunrise"
```

Both print the progress while the job runs, save `output.mp4`, and print the billed seconds.

### cURL

```bash
BASE=https://argolink.io/v1

# 1. Submit: the response carries request_id
curl $BASE/videos/generations \
  -H "Authorization: Bearer $SEEDANCE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "prompt": "A slow aerial shot over a foggy pine forest at sunrise",
    "duration": 5,
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'

# 2. Poll until status is done (or failed / expired). While pending it reports progress 0-99.
curl $BASE/videos/$REQUEST_ID -H "Authorization: Bearer $SEEDANCE_API_KEY"

# 3. Download the MP4 (409 job_video_not_ready before done, 424 job_failed for a failed job)
curl -L $BASE/videos/$REQUEST_ID/content -H "Authorization: Bearer $SEEDANCE_API_KEY" -o output.mp4
```

### Python

```python
from seedance25 import Seedance25

client = Seedance25()  # reads SEEDANCE_API_KEY, optional SEEDANCE_BASE_URL
job = client.generate(
    "A barista pours latte art in slow motion, warm cafe light",
    "latte.mp4",
    duration=8,
    resolution="1080p",
    aspect_ratio="9:16",
)
print(job["usage"])  # output_seconds, reference_video_seconds, billed_seconds
```

### Node.js

```js
import { Seedance25 } from "./seedance25.mjs";

const client = new Seedance25();
const job = await client.generate(
  "A red fox trots through fresh snow at dawn, low tracking shot",
  { duration: 5, resolution: "480p" },
  "fox.mp4",
);
console.log(job.usage);
```

## Modes

All modes use the same endpoint; the fields you send pick the mode.

| Mode | Fields | Notes | Example |
|---|---|---|---|
| Text to video | `prompt` | only `prompt` is required | [Quick start](#quick-start) |
| First frame | `start_image` | `aspect_ratio` must be `adaptive` (or left out); no references | [image_to_video.py](./examples/image_to_video.py) |
| First + last frame | `start_image`, `end_image` | the model fills the motion between the two | see below |
| Reference | `reference_images`, `reference_videos`, `reference_audios` | name them in the prompt as `@Image 1`, `@Video 1`, `@Audio 1` | [reference_assets.mjs](./examples/reference_assets.mjs) |
| Edit a video | `omni_reference_task_type: "edit"` + `reference_videos[0]` | keeps the source length and ratio; leave out `duration` and `aspect_ratio` | [edit_video.sh](./examples/edit_video.sh) |

First and last frame:

```json
{
  "model": "seedance-2.5",
  "prompt": "Day turns into night over the same skyline as the lights come on",
  "duration": 5,
  "resolution": "720p",
  "aspect_ratio": "adaptive",
  "start_image": {"url": "https://example.com/day.png"},
  "end_image": {"url": "https://example.com/night.png"}
}
```

### Local files

Every asset is an HTTPS URL. A local file is uploaded first and the returned `media_url` goes into the request:

```python
url = client.upload("dance.mp4", "video", "video/mp4")
client.generate("Move like the dancer in @Video 1", reference_videos=[{"url": url}])
```

| Field | Format | Max size | Length |
|---|---|---|---|
| images, `start_image`, `end_image` | JPEG, PNG | 20 MiB | — |
| `reference_videos` | MP4, MOV | 100 MiB | 2–30 s each, 30 s total |
| `reference_audios` | WAV, MP3 | 15 MB | 2–30 s each, 30 s total |
| video to edit | MP4, MOV | 100 MiB | 4–30 s |

The upload URL is valid for 15 minutes and the `media_url` for seven days. An asset outside these limits fails the job with `invalid_input` before generation, and nothing is charged.

## Billing rules worth knowing

- **Per output second**, multiplied by the tier rate in the table above.
- **Reference videos add their seconds.** Billed seconds = output seconds + reference-video seconds (fractions dropped): a 5 s video with a 2.4 s reference bills 7 s. Reference images and audio are free.
- **Editing bills twice the length**: the edited video counts as output and as a reference, so editing a 5 s clip bills 10 s.
- **Failed, rejected or expired jobs cost nothing.**
- The finished job's `usage` returns `output_seconds`, `reference_video_seconds` and `billed_seconds`.

## Migrating from fal

fal-style field names are accepted, so most request bodies only need a new base URL and the model ID:

| fal field | Seedance 2.5 field |
|---|---|
| `image_url` | `start_image` |
| `image_urls` / `video_urls` / `audio_urls` | `reference_images` / `reference_videos` / `reference_audios` |

Differences: `duration` is a whole number of seconds (`"auto"` is rejected), and the job is polled at `/v1/videos/{request_id}` instead of fal's queue.

## FAQ

**How long does a Seedance 2.5 video take?**
About 2–5 minutes for a 4–10 second clip. Poll the status; a busy queue can hold a job longer.

**How many videos can I generate in parallel?**
On ArgoLink an account runs up to 50 Seedance 2.5 jobs at the same time, and the limit does not depend on how much the account has spent. A new fal account starts at 2 concurrent requests and rises with recent spend to 40 on self-serve plans. Over the limit, ArgoLink answers `429 rate_limit_error`; when there is no capacity it answers `503` with a `Retry-After` header. Both are safe to retry, and a job that fails is not billed.

**Can I get 4K or several videos per request?**
No. Seedance 2.5 renders up to 1080p and one video per request (`n` must be 1 or omitted).

**Does the video have sound?**
Yes, by default the model scores the clip itself. Send `generate_audio: false` for a silent video.

**Why was my first-frame request rejected?**
Frame modes take their aspect ratio from the first frame: send `aspect_ratio: "adaptive"` or leave it out, and don't combine `start_image` with reference assets.

**Can I set a seed?**
No. `seed` is not supported on Seedance 2.5 and returns 400, like `watermark: true`.

**What is the cheapest way to try it?**
480p at 4 seconds: 4 × $0.0874 ≈ $0.35 on ArgoLink.
